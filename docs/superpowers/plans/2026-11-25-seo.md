# NEXTOUR 검색 노출(SEO · AEO · GEO) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 이 저장소 CLAUDE.md §4.1 — 각 Task 의 검증이 끝나는 즉시 그 Task 의 체크박스를 `[x]` 로 파일에 써 넣고 커밋한다.

**Goal:** 공개 화면(홈 · 상품 목록 · 상품 상세 · 검색)은 검색 엔진과 AI 검색이 제대로 읽게 하고, 비공개 화면과 Vercel 미리보기는 검색에서 뺀다.

**Architecture:** 운영 주소 · 사이트 이름 · 미리보기 판정 · 페이지 메타 조립은 `src/shared/lib/seo` 한 곳에 둔다. 상품 상세의 구조화 데이터는 상품과 출발일을 이미 함께 받는 `widgets/product-detail` 에 순수 함수로 두고, 페이지가 서버에서 `<script type="application/ld+json">` 으로 넣는다. 사이트맵과 `llms.txt` 는 같은 상품 조회(`getPublishedProductIndex`)에서 만들어 서로 어긋나지 않게 한다.

**Tech Stack:** Next.js 16.2.9 App Router(`cacheComponents: true`), TypeScript strict, Prisma 5, Zod 3, Vitest 2.

**Spec:** `~/Desktop/WorkSpace/portfolio/docs/superpowers/specs/2026-11-20-seo-aeo-geo-design.md` §2 · §4.4 · §4.7 · §5 (저장소 밖 문서 — 커밋 · PR · README 에는 경로를 쓰지 않는다)

## 조사 결과 (2026-11-25)

- 운영 `https://travel-agency-sooty-mu.vercel.app` 의 `/robots.txt` · `/sitemap.xml` · `/llms.txt` 모두 404.
- 메타데이터는 루트 `src/app/layout.tsx` 의 제목 · 설명 하나뿐. 모든 상품 상세가 같은 제목 `Nextour — AI 패키지 여행 예약` 으로 나간다. canonical · 공유 카드 · JSON-LD 없음.
- 운영 Lighthouse 13.4.1 모바일 SEO 기준선: `/` 100, `/products/cmq7cjspo0000q3ixvx26oesg` 100(실패 감사 없음). → 문서에 "점수를 올렸다"고 쓰지 않는다.
- 상품 상세 화면에 보이는 값: 이름(h1), 지역, `N박 M일`, 태그, `aiSummary`(있을 때만, "AI 추천 포인트"), 기준가 `basePriceAdult`원~, 출발일별 성인 · 아동 가격과 마감 상태, 대표 사진 `heroImageUrl`(없으면 자리 그림). `summary` 컬럼은 공개 화면에 나오지 않는다 → 쓰지 않는다. `CLOSED` 상품은 "판매종료" 덮개가 뜨고 출발일 목록이 비어 나온다.

- 비로그인으로 `/mypage` · `/admin` 을 열면 미들웨어가 `/login?callbackUrl=...` 로 307 보낸다.
- 로컬 빌드는 `prisma migrate deploy` 를 먼저 돌리므로 로컬 Postgres(`docker-compose.yml`)가 떠 있어야 한다. 조사 시점에 Docker 데몬은 꺼져 있었다.

## Global Constraints

- 결제 · 예약 도메인 코드는 건드리지 않는다. `src/features/{checkout,booking*,payment*}`, `src/entities/{booking,departure}`, `src/app/api/**`, `src/middleware.ts`, 기존 `page.tsx` 중 `bookings/**` · `checkout` · `mypage` · `login/**` · `reviews/new` 는 수정 금지. 비공개 noindex 는 그 폴더에 **메타데이터만 내보내는 새 layout 파일**로 단다.
- 구조화 데이터 · 메타에는 화면에 보이는 값만 쓴다(위 "조사 결과"의 값). 가격은 화면과 같은 필드(`priceAdult`, `basePriceAdult`)에서, 통화는 `KRW`.
- 새 클라이언트 JS 금지. `'use client'` 파일을 새로 만들지 않는다. JSON-LD 는 서버 컴포넌트가 HTML 에 넣는다.
- 정본(운영) 주소는 상수 `SITE_URL = "https://travel-agency-sooty-mu.vercel.app"`. 미리보기에서도 canonical 은 운영을 가리킨다.
- 미리보기 판정은 `VERCEL_ENV === "preview"` 만. 로컬 · 운영은 색인 허용.
- `robots.txt` 로 비공개 화면을 막지 않는다(막으면 noindex 를 못 읽는다). 운영 robots 는 `/api/` 만 막는다. AI 검색 로봇은 따로 막지 않는다.
- `@/shared/lib/seo` 는 `env` 를 import 하므로 서버 전용이다. `'use client'` 파일에서 import 하지 않는다(CLAUDE.md §8 `photoMime.ts` 사고와 같은 이유). `JsonLd` 는 `env` 를 import 하지 않는다.
- `process.env.X` 직접 접근 금지 → `env.X`(CLAUDE.md §5). `any` · `@ts-ignore` 금지. FSD 깊은 경로 import 금지(barrel 로).
- 게이트: `npm run typecheck` · `npm run lint` · `npm run test` · 빌드. Next 빌드가 SecurityFatalError(업그레이드 권고)로 멈추면 한 번만 재실행한다. Next 업그레이드 금지.
- 커밋: `feat(seo): 한국어 제목` 형식(최근 커밋 `chore: 푸터에 저작권 표기` 와 같은 한국어 제목) + 본문 2~5줄에 왜 그렇게 했는지. 면접관이 읽는 글이라 사람이 쓴 문체로, 나열 · 이모지 · 유행어 금지.
- 공개 문서(README · ADR · 커밋 · PR)에 저장소 밖 경로(`~/Desktop/...`, `.superpowers/...`)를 쓰지 않는다. 구글 리치 결과 테스트는 자동화하지 못하니 "했다"고 쓰지 않는다.

## 설계에서 바꾼 두 가지 (ADR-0064 Alternatives 에 남긴다)

1. **홈 `WebSite` 에 `SearchAction` 을 넣지 않는다.** 구글은 2024-11 에 사이트 링크 검색창 표시를 끝냈다. 설계 §2 가 FAQ 구조화 데이터를 뺀 이유("효과 없이 마크업만 늘어난다")와 같다. `WebSite` 의 `name` · `url` 은 검색 결과의 사이트 이름에 쓰이므로 남긴다.
2. **`/compare` 는 noindex(링크는 따라감).** 담아 둔 상품 id(`?compareIds=`)가 있어야 내용이 생기고, 없으면 "비교할 상품이 없습니다"뿐인 화면이다. 검색에 걸리면 빈 화면으로 들어온다. 사이트맵에도 넣지 않는다.
