# 2026-05-23 — PDP ISR 복귀 (A4)

> **For agentic workers:** REQUIRED SUB-SKILL: `superpowers:executing-plans`. 각 Task 의 모든 `- [ ]` 는 구현·검증 직후 그 자리에서 `- [x]` 로 갱신 (CLAUDE.md §4.1).

**Goal:** PDP(`/products/[id]`) 에서 `searchParams.compareIds` 의존을 제거해 `revalidate=3600` ISR 로 복귀시키고, 비교 카트 콘텐츠는 클라이언트가 Route Handler 로 직접 fetch 하도록 전환한다.

**Architecture:** Option A — client-side fetch. `FloatingCompareCart` 가 `useEffect` + `AbortController` 로 `/api/compare/products?ids=...` 를 호출하여 자체적으로 카트 콘텐츠를 가져온다. 서버는 더 이상 `searchParams.compareIds` 를 읽지 않으므로 PDP 페이지가 정적 prerender 가능해진다.

**Tech Stack:** Next.js 15 App Router (Route Handler, ISR), React 19 (`useEffect`, `AbortController`), 기존 `parseCompareIds` · `getProductsByIds` 재사용.

## Context

- A1(상품 비교) PR 에서 `/products/[id]/page.tsx` 가 `await searchParams` 로 `compareIds` 를 읽어 `getProductsByIds(compareIds)` 를 prefetch 하기 시작 → Next 15 가 자동으로 페이지를 dynamic 으로 분류. 본 plan 은 그 부수효과를 청산한다.
- `FloatingCompareCart` 는 이미 `'use client'` + `useSearchParams()` 사용 중. 서버 prefetch 의 유일한 목적은 **SSR 카트 콘텐츠 깜빡임 회피**. 이 prefetch 만 client-side fetch 로 옮기면 PDP 서버는 더 이상 sp 의존 0.

- `FloatingCompareCart` 는 PDP + `/products` 목록 페이지 두 곳에서 사용. props 시그니처 변경 시 양쪽 모두 수정 필요. 목록 페이지는 검색 필터(`search`, `destination` 등) 로 어차피 dynamic 이지만 FCC props 통일을 위해 함께 정리.
- 한 줄 코멘트 (`PDP는 본래 1시간 ISR 대상`, page.tsx:13-16) 와 직접 연결되는 후속 작업.

## Design Decisions

### 1. Route Handler — `GET /api/compare/products?ids=<csv>`
- Path: `src/app/api/compare/products/route.ts`. App Router Route Handler.
- 입력: 쿼리스트링 `ids=cuid1,cuid2,cuid3`. `parseCompareIds` 재사용으로 client/server 파싱 drift 0.
- 처리: `getProductsByIds(ids)` 호출 → `CartProduct[]` 모양(`{id, title, heroImageUrl}`) 으로 매핑.
- 응답: `{ products: CartProduct[] }`.
- 캐시: 데이터 레이어가 이미 `unstable_cache` (1h TTL) 로 메모이즈. Route Handler 자체는 동적(searchParams 의존) 이지만 underlying DB hit 은 압축. 추가로 `Cache-Control: public, max-age=30, s-maxage=300, stale-while-revalidate=60` 헤더로 브라우저/CDN 캐시 적용.

### 2. FloatingCompareCart 클라이언트 fetch
- `Props.products` 제거 — FCC 는 더 이상 server-prefetched 데이터를 받지 않는다.
- `useEffect` 에서 `ids` 변화 감지 → `AbortController` 로 wrapping 된 fetch.
- Cleanup: `controller.abort()` 호출 — Frontend Expert critical rule (cleanup 누락 금지) 충족.
- State: `loading | error | ready`. loading 시 `ids.length` 만큼 skeleton placeholder (실 카트와 동일 높이 유지로 layout shift 방지).
- Dependency key: `ids.join(",")` (primitive 문자열) → stable 비교.

### 3. PDP page 정적 ISR 복귀
- `await searchParams` + `parseCompareIds` + `getProductsByIds` 제거.
- `Promise.all` 에서 `getProductsByIds(compareIds)` slot 제거 → 5병렬 (product/departures/inWishlist/reviewStats/reviewPage).
- `<FloatingCompareCart products={...} />` → `<FloatingCompareCart />` (props 없음).
- `export const revalidate = 3600` 명시 — 1시간 ISR.
- `searchParams: Promise<...>` 타입 인자도 제거 (사용 안 함).
- ⚠️ **한계**: `auth()` + `isInWishlist` 가 여전히 동적 트리거. PDP 가 *완전한* 정적 ISR 이 되려면 wishlist 도 동일 client-fetch 패턴으로 옮겨야 함 → 본 plan **Out of Scope** (별도 plan).
  - 그러나 `revalidate=3600` 자체는 안전하게 명시 — Next 가 dynamic 으로 강등하더라도 데이터 캐시 TTL 힌트로 작동, 후속 auth island 분리 시 즉시 ISR 활성.

### 4. 상품 목록 page 정리 (일관성)
- `/products/page.tsx` 도 동일 패턴 — `compareIds` prefetch 제거 + FCC props 제거.
- 목록 페이지는 검색 필터로 어차피 dynamic 유지이나, FCC 사용처 일관성·prefetch 비용 절감 효과.

### 5. NO-REAL-MONEY 무관

- [x] **Step 1: Route Handler 작성** — Zod (querystring) 가드 + `parseCompareIds` 재사용 + `getProductsByIds` 위임 + JSON 응답 + Cache-Control 헤더

```ts
import { NextRequest, NextResponse } from "next/server";

import { getProductsByIds } from "@/entities/product";
import { parseCompareIds } from "@/features/product-compare/model/compareIds";

// GET /api/compare/products?ids=<cuid>,<cuid>,...
// FloatingCompareCart 가 hydration 후 카트 콘텐츠를 client-fetch 하는 엔드포인트.
// `parseCompareIds` 가 cuid 정합·중복 제거·MAX_COMPARE 캡을 모두 강제하므로
// 별도 Zod 가드 불필요(파싱 자체가 가드). 결과가 빈 배열이면 빈 응답.
//
// 데이터: getProductsByIds 가 unstable_cache(1h TTL + per-id tag) 로 메모이즈.
// Cache-Control: 브라우저 30s + CDN 5min + SWR 60s. 사용자가 카트에 add/remove
// 시 URL ids 변경 → 새 cache key → 즉시 신선. 동일 URL 재진입은 cache hit.
export async function GET(req: NextRequest) {
  const idsParam = req.nextUrl.searchParams.get("ids") ?? undefined;
  const ids = parseCompareIds(idsParam);

  if (ids.length === 0) {
    return NextResponse.json({ products: [] });
  }

  const products = await getProductsByIds(ids);

  return NextResponse.json(
    {
      products: products.map((p) => ({
        id: p.id,
        title: p.title,
        heroImageUrl: p.heroImageUrl,
      })),
    },
    {
      headers: {
        "Cache-Control":
          "public, max-age=30, s-maxage=300, stale-while-revalidate=60",
      },
    },
  );
}
```

### Task 2 — FloatingCompareCart 클라이언트 fetch + skeleton

**Files:**
- Modify: `src/features/product-compare/ui/FloatingCompareCart.tsx`

- [x] **Step 1: props.products 제거 + useEffect+fetch+skeleton 구현**

```tsx
"use client";

import { useEffect, useState } from "react";
import Link from "next/link";
import Image from "next/image";
import { useSearchParams } from "next/navigation";
import {
  parseCompareIds,
  serializeCompareIds,
  MAX_COMPARE,
} from "../model/compareIds";
import { CompareRemoveButton } from "./CompareRemoveButton";

type CartProduct = {
  id: string;
  title: string;
  heroImageUrl: string | null;
};

// SSR prefetch 의존을 제거하고, hydration 후 자체적으로 카트 콘텐츠 fetch.
// 이 변경으로 부모 RSC(PDP)가 searchParams 의존 0 → ISR 복귀 가능.
//
// 라이프사이클:
//   - ids 변화 시 AbortController 로 이전 요청 취소 후 재요청
//   - loading 상태에 ids.length 만큼 skeleton placeholder 렌더 — layout shift 0
//   - cleanup 으로 unmount 시 in-flight 요청 abort (Frontend Expert R)
export function FloatingCompareCart() {
  const searchParams = useSearchParams();
  const idsCsv = searchParams.get("compareIds") ?? "";
  const ids = parseCompareIds(idsCsv);

  const [products, setProducts] = useState<CartProduct[] | null>(null);
  const [errored, setErrored] = useState(false);

  // dependency key 는 string primitive 로 stable 비교.
  const idsKey = ids.join(",");

  useEffect(() => {
    if (ids.length === 0) {
      setProducts([]);
      setErrored(false);
      return;
    }
    const controller = new AbortController();
    setErrored(false);
    setProducts(null); // loading
    fetch(`/api/compare/products?ids=${encodeURIComponent(idsKey)}`, {
      signal: controller.signal,
    })
      .then((r) => (r.ok ? r.json() : Promise.reject(new Error("HTTP " + r.status))))
      .then((d: { products: CartProduct[] }) => setProducts(d.products))
      .catch((e: unknown) => {
        if (e instanceof DOMException && e.name === "AbortError") return;
        setErrored(true);
      });
    return () => controller.abort();
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [idsKey]);

  if (ids.length === 0) return null;

  const isLoading = products === null && !errored;
  // URL 의 ids 순서대로 정렬해 사용자가 담은 순서를 보존.
  const ordered = products
    ? ids
        .map((id) => products.find((p) => p.id === id))
        .filter((p): p is CartProduct => Boolean(p))
    : [];

  return (
    <div
      role="region"
      aria-label="비교 카트"
      className="fixed bottom-4 left-1/2 z-40 -translate-x-1/2 rounded-2xl border border-gray-200 bg-white px-4 py-3 shadow-lg"
    >
      <div className="flex items-center gap-3">
        <p className="text-sm font-medium text-gray-900">
          비교 카트 ({ids.length}/{MAX_COMPARE})
        </p>
        <div className="flex items-center gap-2">
          {isLoading &&
            ids.map((id) => (
              <div
                key={id}
                aria-hidden="true"
                className="h-12 w-12 animate-pulse rounded-md bg-gray-200"
              />
            ))}
          {errored && (
            <span className="text-xs text-red-600">
              카트 정보를 불러오지 못했습니다.
            </span>
          )}
          {!isLoading &&
            !errored &&
            ordered.map((p) => (
              <div key={p.id} className="relative h-12 w-12 overflow-hidden rounded-md border border-gray-100">
                {p.heroImageUrl && (
                  <Image
                    src={p.heroImageUrl}
                    alt={p.title}
                    fill
                    sizes="48px"
                    className="object-cover"
                  />
                )}
                <CompareRemoveButton
                  productId={p.id}
                  serialize={serializeCompareIds}
                  className="absolute right-0 top-0"
                />
              </div>
            ))}
        </div>
        <Link
          href={`/compare?ids=${encodeURIComponent(idsKey)}`}
          className="ml-2 rounded-md bg-indigo-600 px-3 py-1.5 text-xs font-semibold text-white hover:bg-indigo-700"
        >
          비교 보기
        </Link>
      </div>
    </div>
  );
}
```

> ℹ️ 위 JSX 구조(컨테이너 div className, "비교 카트" 헤더, Link href 등) 는 기존 FCC 의 시각적 표현을 보존하는 reference 다. **실제 구현 시 기존 파일의 JSX (return 이하) 를 그대로 사용**하고 본문에서 `products` prop 의존만 위 라이프사이클(useEffect/skeleton/error/ordered) 로 대체할 것. 두 곳의 import (Link, Image 등) 가 이미 동일하므로 변경 폭은 최소.
