# M-AUTH 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기존 NextAuth.js v5 + Resend 매직링크 + Kakao OAuth 구현을 정비하고, 로컬 개발 콘솔 폴백·RSC 헬퍼·미들웨어·시드 사용자를 추가하여 M-AUTH MVP를 완료한다.

**Architecture:** 매직링크 + 카카오 OAuth + database 세션(Prisma Adapter). 모든 RSC는 `entities/user`의 `getCurrentUser()` 헬퍼를 통해 세션 접근. `auth()` 직접 호출 금지(FSD R3). 보호 라우트는 `middleware.ts`에서 일괄 처리.

**Tech Stack:** Next.js 15 App Router, TypeScript, NextAuth.js v5.0.0-beta.25, @auth/prisma-adapter 2.7, Resend 4.0, Prisma 5, PostgreSQL, Zod 3, Vitest 2

**Applied Skills:** `enforce-fsd`, `clean-code-react`

**Spec:** `docs/superpowers/specs/2026-05-13-auth-design.md`
